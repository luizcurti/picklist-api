# Deployment (AWS)

The `messaging` profile of `docker-compose.yml` runs on AWS, deployed by
GitHub Actions on every push to `main`:

```
             HTTPS                HTTP (CloudFront ranges only)
client ──► CloudFront ──────────► ALB ──► ECS Fargate: api ─────┐
                                                                ├─► RDS PostgreSQL 17
             ECS Fargate: inventory-worker ◄──┐                 ├─► ElastiCache Redis (TLS + AUTH)
             ECS Fargate: audit-worker   ◄────┤                 │
                                              └── ECS Fargate: rabbitmq
                                                  (rabbitmq.picklist.internal, Cloud Map)
```

| docker-compose service  | AWS                                                                                     |
| ----------------------- | --------------------------------------------------------------------------------------- |
| `api`                   | ECS Fargate service behind an ALB, HTTPS through CloudFront's default certificate       |
| `inventory-worker`      | ECS Fargate service (same image, different command)                                     |
| `audit-worker`          | ECS Fargate service (same image, different command)                                     |
| `postgres`              | RDS PostgreSQL 17 (`db.t4g.micro`), TLS via `sslmode=no-verify` in `DATABASE_URL`       |
| `redis`                 | ElastiCache Redis 7 (`cache.t4g.micro`), AUTH token + TLS (`rediss://` in `REDIS_URL`)  |
| `rabbitmq`              | ECS Fargate service (`rabbitmq:4-alpine`), reached through a Cloud Map private DNS name |
| `observability` profile | Not deployed: `OTEL_SDK_DISABLED=true`, logs in CloudWatch (`/ecs/picklist-app`)        |

Notes:

- **Secrets** (`API_KEYS`, `DATABASE_URL`, `REDIS_URL`, `RABBITMQ_URL` and the
  RabbitMQ password) are generated by Terraform and stored as SSM SecureString
  parameters under `/picklist/`; ECS injects them as environment variables.
- **RabbitMQ** is a single container without persistence: queued messages are
  lost if its task restarts. Amazon MQ would be the managed alternative, at a
  much higher hourly cost for a demo.
- **Network**: public subnets and no NAT gateway (tasks get a public IP to
  reach ECR and SSM). Only the ALB accepts traffic from outside the VPC, and
  only from CloudFront's origin-facing ranges; PostgreSQL, Redis and RabbitMQ
  only accept the API and worker tasks.
- **`TRUST_PROXY=2`** (CloudFront, then the ALB) makes the rate limiter key on
  the client IP instead of the ALB's.
- **`/metrics`** is answered with a 404 by the ALB: it is unauthenticated and
  meant for a Prometheus inside the network.

## One-time setup

Requirements: Terraform >= 1.10, AWS CLI credentials (admin) of the target
account, and the GitHub CLI logged in with admin access to the repository.

```bash
scripts/bootstrap.sh
```

It applies [`bootstrap/`](../bootstrap) (an S3 bucket for the Terraform state
and an IAM role GitHub Actions assumes through OIDC, scoped to the `picklist-*`
resources and the `production` environment), then creates the `production`
GitHub environment with the `AWS_DEPLOY_ROLE_ARN`, `TF_STATE_BUCKET` and
`AWS_REGION` variables. On an account where no other project created the GitHub
OIDC provider yet, run `scripts/bootstrap.sh -var="create_oidc_provider=true"`.

## Deploy

Every push to `main` deploys once the checks pass; to deploy without a push:

```bash
gh workflow run ci.yml --repo luizcurti/picklist-api --ref main
```

The **Deploy to AWS** job creates the ECR repository, builds and pushes the
image, applies [`infra/`](../infra) (the first run takes ~15 minutes, mostly
RDS and ElastiCache), waits for the four ECS services and runs
[`scripts/smoke-test.sh`](../scripts/smoke-test.sh) against the live API:
readiness, API-key auth, product CRUD, and a pick sent twice with the same
`Idempotency-Key` that must come back with the same `pickId` and decrement the
stock exactly once through RabbitMQ and the inventory worker. The run summary
shows the API URL.

## Try it

```bash
API=https://xxxx.cloudfront.net   # from the run summary
KEY=$(aws ssm get-parameter --with-decryption --name /picklist/API_KEYS \
  --query Parameter.Value --output text)
API_URL=$API API_KEY=$KEY scripts/smoke-test.sh
```

The OpenAPI docs are at `$API/docs` (use **Authorize** with the key).

## Destroy

RDS, ElastiCache, the ALB and the Fargate tasks are billed by the hour. Tear the
stack down when you are done (the bootstrap resources are kept):

```bash
gh workflow run destroy.yml --repo luizcurti/picklist-api --ref main -f confirm=destroy
```

Recreate it with the deploy command above.
